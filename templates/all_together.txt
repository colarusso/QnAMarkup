Title: All Together Now
Description: A sample QnA showing how you can use loadQnA to load a QnA and run it as part of another "host" QnA. The first argument is the location of the QnA, the second is the name of a variable (Q tag) in the target QnA that we want to replace with the third argument, a variable (Q tag) in this interview. This will make it so a user navigating to the variable in the target will instead end up back here at the varaible in the host.

Q(start): Which interview would you like to run?
A[javascript:loadQnA('https://www.qnamarkup.org/templates/cats.txt','end','next')]: Cat videos
A[javascript:loadQnA('https://www.qnamarkup.org/templates/game.txt','end','next')]: Shall we play a game?
A[javascript:loadQnA('https://www.qnamarkup.org/templates/zork_mini.txt','thanks','next')]: Zork mini preview

Q(next): That was fun. How about another interview?
